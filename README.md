# منصة تحضير التكوين — Google Sheets + Apps Script

تطبيق ويب يخدم 60 مديرية تربية (58 ولاية، والجزائر مقسّمة إلى شرق/وسط/غرب) مع حساب للوزارة.
البيانات تُخزَّن في ملف Google Sheet، والمديريات لا تصل إلى الملف مباشرة بل عبر التطبيق فقط.

## الملفات
| الملف | الدور |
|---|---|
| `Config.gs` | المديريات، المواد، الرتب، عناوين الجداول والقوائم (عدّله عند الحاجة) |
| `Code.gs` | الخادم: التهيئة، الدخول، حفظ وقراءة البيانات، لوحة الوزارة |
| `Index.html` / `Styles.html` / `Client.html` | الواجهة (عربية RTL) |
| `appsscript.json` | إعدادات المشروع (منطقة Africa/Algiers، نشر كتطبيق ويب) |

## النشر
1. أنشئ ملف Google Sheet جديداً (يملكه حساب الوزارة، **ولا تشاركه مع المديريات**).
2. من الملف: **الإضافات ← Apps Script**، وانسخ الملفات أعلاه (أو استعمل `clasp push`).
3. (اختياري) لتحديد كلمة مرور الوزارة الأولية: **إعدادات المشروع ← خصائص النص** وأضف `MINISTRY_INITIAL_PASSWORD`. وإلا تُولَّد عشوائياً وتظهر مرة واحدة.
4. شغّل الدالة **`setupAccounts()`** مرة واحدة فقط ← يُنشئ أوراق `Users` و`Counts` و`Lists` و61 حساباً.
5. **نشر ← نشر جديد ← تطبيق ويب**: تنفيذ باسم «أنا»، الوصول «أي شخص».
6. وزّع رابط التطبيق على المديريات.

## الحسابات
| الحساب | اسم المستخدم | كلمة المرور الأولية |
|---|---|---|
| مديرية ولاية (مثال أدرار 01) | `de01` | `Educ01` |
| الجزائر شرق | `dee16` | `Educe16` |
| الجزائر وسط | `dec16` | `Educc16` |
| الجزائر غرب | `deo16` | `Educo16` |
| الوزارة | `minedu` | تُولَّد عند التهيئة |

> ⚠️ لأن النمط معلن في المستودع، **يُفرض تغيير كلمة المرور عند أول دخول**، ولا تُقبل كلمة المرور الأولية كبديل.
> كلمات المرور تُخزَّن مُجزّأة (SHA-256 + salt) وليس نصاً. بعد 5 محاولات خاطئة يُحظر الحساب 10 دقائق.
> نسيان كلمة المرور: من لوحة الوزارة زر 🔄، أو من المحرر `resetPassword('de05')`.

## كيف تعمل الصلاحيات
- المديرية ترى وتعدّل بياناتها فقط؛ المعرّف يُؤخذ من الجلسة في الخادم ولا يُقبل من المتصفح.
- الوزارة قراءة فقط: لوحة متابعة، اختيار مديرية منفردة، أو «كل المديريات» (مجاميع الجداول 01/02/03/05 وقوائم مجمّعة).
- الجدول 03 = 01 + 02 تلقائياً، والجدول 05 = مجموع مراكز الجدول 04 تلقائياً، مع تنبيه إذا اختلف المجموعان.

## الطباعة و PDF
- **تحميل PDF**: يُولَّد في المتصفح بمكتبة html2pdf (A4، الجداول أفقية والقوائم عمودية).
- **طباعة**: نافذة الطباعة ثم «حفظ كـ PDF» (بديل إن حُجب التحميل).

## تخصيص
- المواد: `SEC_SUBJECTS` و`MID_SUBJECTS` و`PRI_SUBJECTS` في `Config.gs`. **قوائم المواد الحالية مبنية على المعتاد لأن عناوين الأعمدة غير مقروءة في الملف الممسوح — طابقها مع النموذج الأصلي.**
- بعد أي تعديل في الكود: **نشر ← إدارة عمليات النشر ← تعديل ← إصدار جديد**.

## النشر على GitHub Pages (الرابط الذي يُوزَّع على المديريات)
الواجهة تُستضاف في `docs/` على GitHub Pages، والبيانات تبقى في Apps Script + Sheet.

1. انشر Apps Script كتطبيق ويب (انظر «النشر» أعلاه) وانسخ الرابط المنتهي بـ `/exec`.
2. افتح `docs/config.js` وضع الرابط:
   ```js
   window.APP_API_URL = 'https://script.google.com/macros/s/XXXX/exec';
   ```
3. ارفع المشروع إلى GitHub، ثم: **Settings ← Pages ← Source: Deploy from a branch ← Branch: main ← Folder: /docs**.
4. الرابط الذي توزعه: `https://<user>.github.io/<repo>/`
5. بعد أي تعديل على `Index/Styles/Client.html` شغّل `python3 tools/build_pages.py` لتحديث `docs/index.html` ثم ارفعه.
6. بعد أي تعديل على `Code.gs` أو `Config.gs` أنشئ **إصداراً جديداً** من النشر في Apps Script (الرابط لا يتغير).
